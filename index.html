📖 Which Way to Go! - Official Rules

Goal: Travel from START to STOP across Dhaka with maximum points and leftover currency.

🎁 Opening Ability Card Draft

At the start of the game, each player draws 2 random Ability Cards and chooses 1 to keep secretly in hand before traveling begins.

🚦 Traffic System

In Round 1, all roads are Medium traffic. From Round 2 onward, a 6-sided dice roll sets which road colors (Red, Green, Blue) are Heavy, Medium, and Light.

🚗 Vehicles & Speed Chart

  • 🏃 Walk/Run: Free (0 cost). Always earns 3 pts.
  • 🏍️ Bike: Cost 3. Speed: 3 (Heavy), 6 (Med), 9 (Light).
  • 🚗 Car: Cost 6. Speed: 9 (Heavy), 12 (Med), 18 (Light).
  • 🚌 Bus: Cost 3. Speed: 6 (Heavy), 9 (Med), 12 (Light). Only boards/alights at Bus Stations.
  • 🚂 Train: Cost 9. Fixed 15 pts speed! Runs exclusively on Railroad tracks and ignores traffic completely.

🎴 Ability Cards

Landing on an 'A' node lets you draw 2 cards: keep 1, discard 1. Cards give speed boosts, extra money, roadblock controls, or steal tokens and points from opponents.

🏁 Scoring & Endgame

  • Points milestones: Crossing 33, 66, and 100 pts awards +9 currency (3 coins).
  • Fastest Player Bonus: First to reach STOP gets +15 points.
  • Money Bonus: 1 leftover currency = +1 point.
  • Distance Penalty: Remaining players lose 6 points per stop from STOP.

🚀 Publish Online via GitHub Pages

Yes! You can publish this entire game completely free on GitHub Pages. Because Which Way to Go! uses 100% client-side HTML5 Canvas, Web Audio API, and serverless WebSocket rooms, it requires zero backend hosting cost!

Step 1: Push Code to your GitHub Repository

Commit all the files and push them to your repository (umahbub/WhichWay2Go):

git add .
git commit -m "Launch Which Way to Go Online Multiplayer"
git push origin main
Step 2: Enable GitHub Pages in 3 Clicks
  1. Go to your repository on GitHub: github.com/umahbub/WhichWay2Go
  2. Click on Settings ➔ Pages (in the left sidebar).
  3. Under Build and deployment ➔ Source, choose Deploy from a branch.
  4. Select Branch: main, Folder: / (root), and click Save.
Step 3: Share Your Live Game Link!

Within 1–2 minutes, GitHub will build your site and publish it live at:

https://umahbub.github.io/WhichWay2Go/

Anyone with this link can visit on Desktop or Mobile, create a room, share the Game ID, and play together over the internet!
